# exam-study-guide

This skill captures how the y3f exam study guides were made: the multi-stage process, the student's rules, and the shape each course needed. Agents load **[SKILL.md](SKILL.md)**. The details are in `reference/`:

| File | What it holds |
|---|---|
| `SKILL.md` | the 9 stages and their gates, from gathering sources to publishing |
| `reference/student-rules.md` | the student's feedback distilled into rules, and what was tried on IT241 and why it changed |
| `reference/exam-analysis.md` | how to analyze papers, build the concept and priority maps, and predict written questions |
| `reference/it241-v2-format.md` | the reference format: files, card markup, practice items, build checks, read-along |
| `reference/course-variants.md` | IT241, SCI201, STAT101, MATH251 and ENG103, each done its own way, and how to choose |
| `reference/companion-pages.md` | SS-only switch, predicted questions, cheat sheet, formula sheet, T/F sheet, core page, Flooki exams |

It works with the [`read-along`](../read-along) and [`flooki-exam`](../flooki-exam) skills. The guides themselves are in the public site repo, github.com/Y3FAI/y3f, under `2026-fall/<course>/revision/` and `final-prep/`.

## Where it came from

On 2026-11-08 it was written from the Claude Code sessions that built the fall 2026 midterm guides:

- MATH251: 18–19 Oct
- STAT101: 19–22 Oct
- SCI201: 19–21 Oct
- IT241: 23–25 Oct, including the predicted-questions session

It draws on the student's own messages, the plans and reports given at each gate, and the guides' READMEs and build scripts.
