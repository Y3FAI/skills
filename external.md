# External skills

Skills I use that other people publish. They are **not stored in this repo**. Install each one from its source so it keeps getting updates.

Most of them install with the `skills` CLI (`npx skills add <source>`). It keeps track of what it installed in `~/.agents/.skill-lock.json`.
