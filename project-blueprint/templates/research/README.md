# Research

Input, not decisions. The decisions are in [`docs/`](../docs/) and [`docs/adr/`](../docs/adr/).

One file per question. Each starts with the question, the date and the sources, and ends with
what it means for this project. When research leads to a decision, the decision goes to
`docs/decisions.md` (and an ADR); the research file stays as the evidence. Delete research that a
later decision made obsolete; git keeps it.
